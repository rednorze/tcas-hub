# TCAS Hub

เว็บรวมข้อมูลรับสมัคร TCAS รอบ 1 Portfolio — สาขาวิศวกรรมคอมพิวเตอร์

ตอนนี้มีข้อมูลจริงของ **ม.มหิดล** ส่วนจุฬาฯ / มจธ. / สจล. / ม.เกษตร เป็นโครงว่าง (ขึ้นป้าย "เร็วๆ นี้") รอเติมข้อมูล

---

## วิธีขึ้นเว็บด้วย GitHub Pages (ฟรี)

> หมายเหตุ: GitHub ฟรี ต้องตั้ง repo เป็น **Public** ถึงจะเปิด Pages ได้ เว็บนี้เป็นข้อมูลสาธารณะอยู่แล้วจึงไม่มีปัญหา — แค่อย่าใส่ข้อมูลส่วนตัว (เกรดจริง, เลขบัตรประชาชน, ไฟล์พอร์ตจริง) ลงใน repo

1. เข้า https://github.com/new สร้าง repo ชื่อ `tcas-hub` เลือก **Public** แล้วกด Create
2. หน้า repo กด **Add file → Upload files** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (`index.html`, โฟลเดอร์ `data`, `README.md`) เข้าไป กด **Commit changes**
3. ไปที่ **Settings → Pages** → หัวข้อ Build and deployment → Source เลือก **Deploy from a branch** → Branch เลือก **main** โฟลเดอร์ **/ (root)** → กด **Save**
4. รอ 1–2 นาที ลิงก์จะขึ้นที่หน้าเดียวกัน: **https://rednorze.github.io/tcas-hub/**

เสร็จแล้วส่งลิงก์นี้ให้ใครก็เปิดดูได้เลย

## วิธีเพิ่มข้อมูลมหาวิทยาลัย/สาขาในอนาคต

แก้ไฟล์เดียวคือ `data/data.js` — ไม่ต้องแตะ `index.html`

- **เติมข้อมูลมหาลัยที่ยังเป็น "เร็วๆ นี้":** หา object ของมหาลัยนั้น (เช่น `chula`) แล้วเติม field ให้ครบเหมือนของมหิดล จากนั้นเปลี่ยน `status: "soon"` เป็น `status: "ready"`
- **เพิ่มมหาลัยใหม่:** คัดลอกทั้ง block ของมหิดลมาวาง แก้ `id`, `university`, `logo`, `color` และข้อมูลข้างใน
- **เพิ่มสาขาในมหาลัยเดิม:** เพิ่ม object ใน array `programs` ของมหาลัยนั้น

หลังแก้ไฟล์ อัปโหลดทับขึ้น GitHub อีกครั้ง (Add file → Upload files) เว็บจะอัปเดตเองใน 1–2 นาที

## โครงไฟล์

```
tcas-hub/
├─ index.html          หน้าเว็บ (เมนู + แดชบอร์ด — ไม่ต้องแก้)
├─ data/
│   └─ data.js         ข้อมูลทั้งหมด (แก้ที่นี่)
└─ README.md
```

## เปิดดูในเครื่องก่อน (ไม่บังคับ)

ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย ทำงานได้เหมือนบนเว็บจริง
